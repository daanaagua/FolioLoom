# 2026-09-05 — v1.7.1 reliability patch

## Scope and result

- Fixed five reproduced v1.7.0 defects: cascading retrofit replacements,
  multi-form rule ID collisions, incomplete tie-conflict detection, abandoned
  leases blocking resume, and quadratic terminology projection.
- First added six failing reproductions, then implemented the fixes. Added a
  separate failing historical-corruption audit case before strengthening the
  store/export gate. Follow-up coverage exercises three real lease contenders,
  alias-specific partial overrides, read-only audit, and rollback.
- Local edits now use one original-text span set, reject overlap with protected
  surfaces, and preserve untouched text. Store audit replays relevant edit
  ancestry rather than trusting a persisted `clean` flag or plan hash alone.
- Rules are grouped by identity and indexed by spelling. Both translation
  projection and durable conflict validation reuse a compiled index within each
  operation. This is not a cross-snapshot cache and introduces no cache staleness.
- SQLite holds a cross-process lease guard until release/exit; the legacy `wx`
  file is preserved for compatibility. Only ESRCH for a well-formed local owner
  is considered proof of death. PID reuse remains conservatively blocked.
- No storage schema migration. Existing manuscript and project data were not
  used or changed; all destructive test cleanup targets synthetic temp fixtures.
- Build-only xmldom updated to 0.8.15 without a broad dependency refresh.

## Verification

- Core: 1,000 pass / 1 environment skip; desktop Node: 113 pass / same skip;
  renderer: 67 pass. Core and desktop types and skill env tests pass.
- Synthetic resolver samples, 8 blocks: 100 terms 2 ms; 500 terms 8 ms;
  2,000 terms 22 ms (old samples: 119 / 2,969 / 71,100 ms).
- Actual store API produces `新船长走来。新船长停下。` from
  `舰队长走来。船长停下。`. Reintroducing the historical doubled prefix into
  a synthetic database makes strict export fail before any output directory
  exists. Read-only audit detects it; rollback restores the original version.
- Detailed compatibility, security-audit limitations, and release verification
  summary: [v1.7.1 notes](../docs/releases/v1.7.1.md).

## Deferred work

- Visual block-range selection, editable per-item diff review, background panel
  updates, store/runner extraction, and packaged-release CI remain follow-ups.
- No live-model 100K run or whole-book quality benchmark in this patch.
