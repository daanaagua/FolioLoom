# Source scope and optional omission review

- New imports retain a hashed source-scope certificate. Excerpt imports can pin a portable original manifest and an explicit range plan. Missing sections, gaps, overlaps, invalid paragraph cuts and selected-text mismatches are rejected. Legacy manifests retain their existing identities.
- Scope certificates enter the certified database source payload, derived-plan checks and export audits without a schema migration. Scope-relative completion remains distinct from whole-original selection. Regeneration is an explicit plan, not proof of a generated replacement.
- `book scope` exposes the original inventory. `book review scan` selects heuristic risks and deterministic unflagged samples without a provider. `book review run/status` use a separate durable journal, explicit call/token/output limits and grounded source/target quotes; they never edit the translation database.
- Restart preserves budgets. Interrupted dispatches retain unknown usage; stale candidates, invalid evidence and provider failures stop review without an automatic retry. Admission exhaustion remains visible through the status command.
- Validation: 1,466 core tests passed, one environment skip; core and desktop type checks passed; desktop build and build-artifact test passed. Two synthetic live provider comparisons used 2,162 known tokens with no unknown usage, identifying an omitted action while accepting a faithful positive paraphrase. Read-only compatibility checks retained the original audit outcomes and hashes of six historical stores.
