## EPUB boundary validation

- Lossless source blocks can retain a trailing paragraph separator. The EPUB
  structural validator previously counted its empty split tail as a paragraph,
  while fragment assembly emits only paragraphs containing source text. Valid
  assembled translations could therefore fail with a paragraph-count mismatch.
- Paragraph comparison now discards only boundary spans containing whitespace.
  Interior spans, nonempty paragraph content, and structural marker ordering and
  placement remain validated unchanged.
- A synthetic regression reproduced the failure before the fix and passed after
  it. Missing paragraphs, merged paragraphs, and dropped markers are still rejected.
  EPUB structure/writer and translation-agent tests: 53 passed; type check passed.
- Full book-runner regression suite: 79 passed.
- The OpenCode bridge accepts a leaked single DeepSeek DSML invocation prefix only
  when its tool name matches the requested tool and the enclosed arguments are
  complete JSON. Multiple calls, wrong tools, prose prefixes, and truncated JSON
  still fail closed. Ten skill/bridge checks passed; recorded-response replay
  preserved the JSON arguments and provider usage exactly.
