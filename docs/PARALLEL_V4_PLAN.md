# parallel_v4 第一版实施计划

1. 建立 SQLite schema、事务接口、知识版本和运行审计。
2. 实现旧项目迁移，导入原文块、旧词库和串行基线译文。
3. 实现严格扫描协议、并行扫描批次和保守归并。
4. 实现按需上下文构造器及硬预算异常。
5. 实现小岛调度器、批次屏障、动态并行度和单写入提交。
6. 以严格模式复用现有两层翻译器，将结果写入影子数据库。
7. 实现影子验证、质量报告、TXT和EPUB导出。
8. 增加数据库、迁移、扫描、调度、故障恢复和导出测试。
9. 用 `incandescence` 项目执行离线迁移与影子状态验收；真实模型全书 A/B 在自动化测试通过后进行。
