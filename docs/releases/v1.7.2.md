# FolioLoom v1.7.2

Live model discovery and a smaller native Pi request path. Windows x64 portable
EXE and ZIP remain the supported builds.

## Model setup

- Model setup scans the provider's live `/models` endpoint after credentials
  become available and offers a manual refresh button.
- Live results include a count and timestamp. Network failures display an
  explicitly labelled built-in fallback; successful empty lists stay empty.
- Refresh preserves the current model, including compatible IDs absent from
  the latest list. Provider, endpoint and credential changes invalidate stale
  responses and trigger a new scan. Returning to a provider also rescans.
- Discovery has an eight-second default deadline, bounds and validates model
  IDs, and excludes echoed credentials. A provider with no fallback fails
  explicitly when discovery is unavailable.
- New DeepSeek configurations use `deepseek-flash`. Known retired routes are
  rejected; newly discovered IDs still need a successful capability check.

## Native Pi efficiency

- Persistence-only revision hashes are omitted from model-facing terminology
  records. Source text, positions, constraints and scopes remain unchanged;
  full audit metadata stays local.
- One fixed 200-term fixture shrank from 86,912 to 57,824 bytes in its terms
  section (33.5%). This is not an end-to-end translation speed claim.
- Equivalent DeepSeek reasoning aliases are deduplicated: seven advertised
  options become four effective candidate strategies. The selected quality
  profile, escalation path and stored fingerprints remain unchanged.

## Validation and compatibility

- The build-only `js-yaml` dependency is updated to 4.3.2 for
  [GHSA-2883-xcg3-v3hh](https://github.com/advisories/GHSA-2883-xcg3-v3hh).
  High/critical audit gates pass; five moderate dependency findings remain.
- Provider, runtime, desktop and renderer regressions cover live/fallback/empty
  discovery, selection retention, stale responses, deadlines, candidate
  deduplication and local-versus-wire terminology metadata.
- A canonical `deepseek-flash` two-chapter run completed in 59.6 seconds with
  four model calls and 17,577 reported tokens. Both windows completed without
  warnings; store audit and strict-export verification passed.
- Model discovery uses a lightweight listing request; translation compatibility
  is checked separately. Services without a usable `/models` endpoint retain
  their labelled built-in options where available.
- Storage remains schema v5. Existing project data and run model IDs are not
  migrated. Back up projects before upgrading. Windows builds remain unsigned.
- The earlier 100K timings remain historical measurements; this release's
  short-run and payload measurements are not whole-book quality benchmarks.

Details: [wire measurement](../reports/2026-09-11-pi-request-wire-measurement.md)
and [model discovery](../reports/2026-09-11-live-model-discovery.md).
