# FolioLoom v1.8.1

Reliable evidence references, durable translation candidates and bounded recovery.
Windows x64 portable EXE and ZIP are the supported builds.

## Evidence and supervision

- Native supervision selects host-issued source and candidate reference IDs instead
  of copying quotations. IDs bind the exact block, text version and Unicode-scalar
  range. Historical quote-based decisions retain strict validation.
- Invalid evidence identifies its array entry, field and block. Repeated identical
  tool errors stop early; planning batches shrink before dispatch when necessary
  to fit the configured model's context capacity.
- Plans and accepted reviews track terminology dependencies. Superseded guidance
  cannot leak through neighboring windows or override the current term projection.

## Durable candidates and recovery

- Complete translation candidates are saved before semantic review; repaired text
  is saved before its next review. Resume reuses unchanged valid candidates without
  repeating translation. Checkpoints are separate from active translations and do
  not authorize export.
- Repair credit survives process restarts. No-progress repairs and exhausted credits
  create a releasable supervision pause. Explicit release retains the candidate and
  permits another bounded repair generation for the affected window.
- Initial translation and terminology revalidation use the same checkpoint service.
  Source, model, knowledge, terminology, style and guidance changes invalidate reuse;
  snapshot ancestry alone does not invalidate identical knowledge.
- Cross-request validation rejection discards its cached candidate. Retry attempts
  cannot enlarge their own budget baseline. Cache-only resumes do not train provider
  latency estimates from local lookup time.
- Reported repair usage remains accounted for if a later review fails. A resume with
  no provider operation has zero incremental translation usage; unknown provider
  usage remains incomplete and blocks strict export.

## Validation and compatibility

- Electron, CSV parsing, test tooling and affected transitive dependencies receive
  security updates. Packaging uses the native-fetch Electron downloader and Node.js
  24. The high-severity dependency audit passes; ExcelJS retains two moderate audit
  findings in its legacy UUID dependency chain.
- Regression gates: 1062 core tests passed with one environment-dependent skip;
  74 renderer tests, core/desktop type checks and the desktop production build passed.
- The offline reliability gate covers typed and framed execution, injected review
  failures, restart recovery, exact accounting, strict export and zero-call completed
  resume. CI includes a 10,000-word synthetic run; 100,000-word synthetic gates cover
  both quality and fast modes. Synthetic output tests execution, not literary quality.
- A real-provider bounded check exercised reference-based revision and a complete
  translation with strict TXT/EPUB verification and no-call resume.
- Storage remains schema v5. Existing backend, model, task-context and supervision
  identities are preserved. Candidates generated before checkpoint support may need
  regeneration; historical response evidence and charges remain intact.
- Windows builds remain unsigned. Back up projects before upgrading.
