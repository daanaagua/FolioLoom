# FolioLoom v1.5.2

本版本为 EPUB 注释与链接保真小版本。翻译吞吐、知识账本和调度策略保持 v1.5.1 不变。

## EPUB 原模板保真

- 新导入的 EPUB 使用 `epub-spine-v2` 提取器记录稳定文本槽。
- 导出时克隆原 EPUB，而不是重新生成一套简化目录和章节。
- 保留原 OPF、spine、nav、CSS、图片、字体和其他非正文资源。
- 保留 `id`、`href`、`epub:type`、脚注跳转、返回链接、跨章节片段链接和外部 URL。
- 链接标签、脚注/尾注正文和非 spine XHTML 注释文档可以随正文翻译。
- 结构槽缺失、重复、乱序，原始哈希变化，或内部链接悬空时 fail closed；最终文件只在校验完成后原子发布。
- TXT、Markdown、DOCX 和旧 EPUB 项目继续使用原有 EPUB 生成器；旧 EPUB 项目若要启用保真导出，需要重新导入原书。

## 本地验收

本地构造并编辑了一本同时包含以下结构的 EPUB：

- 正文 noteref → 非 spine 脚注文件；
- 脚注 backlink → 正文；
- 跨章节 fragment；
- 带查询参数的外部 HTTPS URL；
- deflate 与 stored ZIP 成员；
- 独立 CSS、OPF、nav。

导入、确定性翻译替身、原模板导出和严格校验全部通过。故意删除一个结构槽时，导出拒绝发布最终 EPUB。

可检查的本地产物位于 `folioloom/.local/epub-v1.5.2-smoke/`（该目录不进入 Git）。
