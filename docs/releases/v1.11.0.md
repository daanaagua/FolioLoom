# FolioLoom v1.11.0

- New native desktop and CLI full-book tasks default to direct generation.
- Direct protocol 3 combines translation with typed, source-attested naming entries.
  Stable entities become book-scoped constraints; distinctive terms remain contextual
  preferences, while ordinary or uncertain entries are excluded.
- Fixed concurrent waves collect drafts and merge names in source order. Conflicting
  windows use one frozen repair plan within their original request allowance.
- Name comparison tolerates paired outer quotation/title marks and source-attested
  possessive grammar without rewriting translated prose.
- No default model planning, lexical research, semantic review or closure rounds.
- Exact paragraph coverage, ordered IDs, Unicode and EPUB slot validation remain
  local. Structural fallback and provider retries use bounded persisted allowances.
- Durable response records allow reuse after interruption before window commit;
  completed parallel siblings survive another request's failure.
- Protocol-2 resume can reuse a compatible saved response from an older naming
  context for the same exact input, including after its attempt allowance is spent.
- Unknown provider usage remains separately visible and blocks strict accounting
  acceptance without disabling eligible transient recovery.
- Direct startup validates provider connectivity before reserving attempts. An
  explicit scoped TLS compatibility option retains TLS 1.3 and certificate checks.
- Exhausted transport-only windows can receive an explicit, durable bounded release;
  ordinary restart cannot refresh credit or clear historical unknown usage.
- Existing runs keep their original workflow. The supervised pipeline remains an
  explicit compatibility option; core callers opt in with `workflow: "direct"`.

See [direct translation](../direct-translation.md) for configuration and behavior.
