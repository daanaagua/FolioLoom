# FolioLoom v1.5.3

本版本补齐桌面端 `human_required` 的解释与安全恢复流程。翻译提示词、调度、知识账本、EPUB 导出和严格质量门保持 v1.5.2 不变。

## 需要处理中心

- “翻译运行”不再只显示待处理数量；现在会列出文本块顺序、章节位置、字符数、尝试次数、公开错误码和建议动作。
- 失败按模型服务、返回协议、完整性校验、请求预算、原文结构、本地存储和未知原因分类。
- 渲染器不接收原始错误、模型响应、书稿片段或私人路径；公开投影最多显示 100 项。
- 同一处提供隐私诊断导出入口。

## 一次性安全重试

- 仅 `human_required` 且不存在 `failed` 窗口时开放安全重试。
- 重试前验证原书版本和原模型运行指纹，不允许静默换模型或 effort。
- 复用已有 `EXPORT_INCOMPLETE → reset_missing_windows` 恢复协议：先在影子状态重排缺失窗口，完成块成员、缺失窗口和运行谱系审计，再原子晋升为 pending。
- 每个受阻运行只允许一次自动恢复；再次失败时关闭重试按钮并要求导出诊断，避免无限循环。
- 已完成翻译和知识状态保持不变。

## 验证

- 新增失败分类隐私测试、SQLite 状态投影测试、受审计恢复测试、重复重试封锁测试和桌面交互测试。
- `test`：939 passed、1 skipped、0 failed。
- `desktop:test`：112 passed、1 skipped、0 failed（Node）；67 passed、0 failed（Renderer）。
- Core 与 Desktop TypeScript 类型检查通过。
- Electron Vite 三端生产构建与产物校验通过。
