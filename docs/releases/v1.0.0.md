# FolioLoom v1.0.0

FolioLoom is a continuity-aware translation engine for long-form fiction. This first public release packages the current V5 research and production core under a stable project identity.

## Highlights

- Lossless source ledgers preserve canonical text, scalar positions, hashes, and block lineage.
- Versioned SQLite runs support bounded concurrency, resumable execution, deterministic commits, and independent audits.
- Entity aliases remain evidence-backed and provisional until revalidation supports a canonical link.
- Lexical anchors are frozen once per parallel wave so sibling windows receive the same terminology snapshot.
- Effective style combines a book constitution, narrator and character voices, discourse-mode weights, decaying local state, and a bounded set of compatible examples.
- Translation batches receive deterministic completeness checks and at most one targeted local repair; a failed logical window is isolated instead of contaminating adjacent work.
- Bounded agents may register translation-critical questions, retrieve evidence through restricted tools, and submit auditable conclusions without shell or arbitrary database access.

## Verification

- 204 TypeScript core tests pass on Node.js 24.
- TypeScript type checking passes with `tsc --noEmit`.
- The wider development repository has 690 passing Python tests and 8 passing subtests when the credential-dependent historical experiment is excluded.
- Real-model one-window and three-window gates completed without missing blocks, leaked system text, unresolved validation incidents, or abandoned leases.

These checks establish an initial engineering baseline. They do not constitute a public benchmark of literary quality or a completed full-book endurance run for the final V1.0 configuration.

## Current limitations

- V1.0 is primarily a command-line tool and has no unified GUI.
- The TypeScript core remains in `translator-v5/`; Python V1–V4 code is retained for input adaptation, review, migration, and research history.
- No desktop installer or public npm package is provided.
- Provider configuration remains developer-oriented and the included example is centered on DeepSeek-compatible usage.
- The latest architecture has passed small real-model gates but does not yet have a published full-book benchmark.

## Safety and data ownership

FolioLoom does not include novels, translated books, project databases, model outputs, or API credentials. Source files and derived project state remain local and are excluded from Git by default.

Use FolioLoom only with texts you are authorized to process. You are responsible for the copyright and publication status of source texts and generated translations.
