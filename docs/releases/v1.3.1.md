# FolioLoom v1.3.1

FolioLoom v1.3.1 是一个翻译质量修复版本，解决英文多行标题在保持原段落结构时可能生成倒置中文词序的问题。

## 修复

- 将相邻的短标题行作为一个完整语义单元翻译，允许只在原有标题段落槽位内重新分配措辞。
- `CHILDREN / OF TIME` 现在可自然输出为 `时间 / 之子`，不再生成 `子 / 时间之`。
- 正文仍保持严格的一一段落对应，不放宽跨段移动、合并、拆分或跨文本块污染的校验。
- 正式批量翻译、兼容翻译入口和定向修复入口统一使用同一套段落完整性规则。

## 工程调整

- TypeScript 正式内核目录统一为 `folioloom/`，并同步更新命令、文档与 CI 路径。
- 增加多行标题提示词和段落槽位边界的回归测试。

## 下载方式

- **FolioLoom-portable-win-x64.zip（推荐）**：完整解压后运行 `FolioLoom.exe`。
- **FolioLoom-portable-win-x64.exe**：单文件便携版。
- **SHA256SUMS.txt**：用于校验下载文件。

两个程序包均仅支持 Windows x64。项目不捆绑模型或 API Key。由于当前程序尚未购买代码签名证书，Windows 可能显示 SmartScreen 提示。
