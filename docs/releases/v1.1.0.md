# FolioLoom v1.1.0

FolioLoom v1.1.0 是首个可供普通用户直接运行的 Windows 桌面版本，面向长篇小说及其他长文本的连续性翻译。

## 下载方式

- **FolioLoom-portable-win-x64.zip（推荐）**：解压后运行 `FolioLoom.exe`，目录结构完整，便于查看和迁移。
- **FolioLoom-portable-win-x64.exe**：单文件便携版，无需安装。
- **SHA256SUMS.txt**：用于校验下载文件是否完整。

两个程序包均仅支持 Windows x64。项目没有捆绑模型或 API Key，首次使用时需要接入自己的模型服务。由于当前程序尚未购买代码签名证书，Windows 可能显示 SmartScreen 提示。

## 本版主要内容

- 支持 TXT、EPUB、DOCX 和 Markdown 书稿导入。
- 提供 DeepSeek、Kimi、百炼、火山引擎、OpenAI、硅基流动及自定义 OpenAI 兼容服务的图形化配置。
- API Key 通过 Electron 安全存储保存，不写入项目数据库或普通配置文件。
- 支持英语、日语和韩语源文的编码识别、分块估算与长篇翻译策略。
- 使用无损源账本保证原文覆盖，避免漏段、重段和分块错位。
- 在 SQLite 中维护实体、别名、术语、叙事记忆与版本历史。
- 支持 JSON、YAML、CSV、XLSX 术语或知识数据导入，并提供字段映射及冲突预览。
- 提供快速试译、知识工作台、诊断信息和可恢复的翻译任务。
- 通过定向证据检索、动态叙事记忆和自适应并发，降低长篇翻译中的名称漂移及上下文丢失。

## 使用建议

首次使用时，建议先导入书稿并运行一小段试译，确认模型接口、译文风格和速度符合预期，再启动长篇任务。请只处理自己有权使用和翻译的文本。
