# FolioLoom v1.3.0

FolioLoom v1.3.0 补齐了桌面端从“试译”到“整本翻译并交付文件”的完整流程。普通用户现在可以在 GUI 中运行整本任务，并直接导出可阅读的中文 TXT、双语 TXT 和 EPUB，无需操作命令行或手动修改 SQLite。

## 本版重点

### 整本翻译

- “翻译运行”页面新增质量模式和快速模式。
- 页面持续显示当前阶段、完成比例、文本块数量和运行状态。
- 同一时间只允许一个整本任务写入，避免多个任务争用同一状态库。
- 可以安全暂停；关闭应用后重新打开，仍可沿用原模型、模式和状态继续运行。
- 已完成的文本块持久写入书稿自己的 SQLite 状态库，不会因应用退出而丢失。

### 直接导出完整译文

- “导出”页面会列出当前书稿中可交付的完整运行。
- 支持导出纯中文 TXT、原文与译文对照 TXT、EPUB，或一次导出全部格式。
- 用户只需选择保存目录；不需要寻找数据库、运行编号或内部项目文件。
- 输出文件沿用原书名，并生成审计报告和运行指标。
- 导出前会重新检查原文覆盖、文本块连续性、译文完整性和运行状态。
- 文件先写入临时目录，全部验证通过后才发布到目标目录，避免留下看似完成的残缺文件。
- 不覆盖同名旧译稿；再次导出会创建新的安全目录。

## 同时完善

- 整本运行和导出均使用明确的 Electron IPC 白名单，渲染页面不能提交任意本机路径。
- 导出目录通过一次性授权传递，API Key 仍只保存在 Electron 主进程的安全存储中。
- 修复桌面导入项目在导出时退化为 `original` 文件名的问题。
- 增加“导入—暂停—重启恢复—完成—三种格式导出—重新校验”的端到端回归测试。
- 命令行翻译与导出流程保持兼容。

## 使用方法

1. 解压 `FolioLoom-portable-win-x64.zip`，运行目录中的 `FolioLoom.exe`。
2. 导入 TXT、EPUB、DOCX 或 Markdown 书稿。
3. 连接自己的模型 API，完成兼容性检查并先试译一小段。
4. 进入“翻译运行”，选择质量模式或快速模式并开始整本翻译。
5. 任务完成后进入“导出”，选择格式和保存目录。

从 v1.1.x 升级时，建议把新版 ZIP 解压到一个新目录，不要覆盖旧程序目录。书稿项目、翻译状态和已安全保存的模型配置位于用户数据目录，不会因为更换程序目录而删除。

## 下载方式

- **FolioLoom-portable-win-x64.zip（推荐）**：完整解压后运行 `FolioLoom.exe`。
- **FolioLoom-portable-win-x64.exe**：单文件便携版。
- **SHA256SUMS.txt**：用于校验下载文件。

两个程序包均仅支持 Windows x64。项目不捆绑模型或 API Key。由于当前程序尚未购买代码签名证书，Windows 可能显示 SmartScreen 提示。

批量审阅队列仍未接入桌面端；导出只接受已经完整翻译且通过审计的运行，不提供把半成品伪装成完整译稿的选项。
