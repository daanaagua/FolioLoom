# FolioLoom 1.4.0

本版本主要解决普通用户遇到“试译失败”后无法提供有效线索的问题，并更新 DeepSeek 模型入口及西欧语言导入链路。

## 一键导出隐私诊断

- 左侧常驻“导出诊断”入口，以及错误面板中的“复制诊断摘要”“导出诊断包”现在可以直接生成反馈材料。
- 诊断事件会标明失败发生在书稿导入、模型探测、翻译、校验、修复还是提交阶段。
- 导出的单个 JSON 文件经过写入时脱敏和发布前递归扫描。
- 诊断包不包含 API Key、Authorization、cookie、原文、译文、提示词、模型原始响应、知识正文、完整私人路径或 SQLite 数据库。
- 日志采用有界轮转；即使日志目录损坏或磁盘写入失败，也不会改变翻译控制流。

## DeepSeek V4 模型入口

- DeepSeek 预设只提供 `deepseek-v4-flash` 和 `deepseek-v4-pro`。
- 已停用的 `deepseek-chat`、`deepseek-reasoner` 会返回明确的 `DEEPSEEK_MODEL_RETIRED`，不会继续进入试译。
- 读取到旧配置时会清除旧模型选择和旧探测结果，但不会删除已经安全保存的 API Key；用户重新选择 V4 模型并测试连接即可。
- 桌面端和命令行共用同一模型白名单。

## 德语、法语和西班牙语

- 自动检测改为从书稿开头、中部和结尾分层取样，减少英文版权页盖过正文语言的情况。
- 导入界面可以手工指定原文语言；低置信文本不再被迫猜测。
- TXT 新增 Windows-1252 支持，保留西欧重音字符、弯引号和长破折号；UTF-8、UTF-16 继续受严格校验。
- 增加德语、法语和西班牙语常见章节标题，并要求独立数字或罗马数字同时具有空行布局证据，减少正文误判。
- 普通词裁决现在作为 `contextual` 负缓存保留，用于避免后续重复判断，但不会作为翻译知识塞进模型上下文。

发布候选使用 Project Gutenberg 德文《变形记》做了真实单窗口门禁：自动检测为德语（置信度 `0.98`），全文 141,034 个 Unicode scalar 完整覆盖，`I.`、`II.`、`III.` 均被识别；一个 4,984 字符正文窗口使用 `deepseek-v4-flash`、`high`，48.3 秒、3 次模型调用完成。原文与译文均为 7 个段落，没有乱码、异常德语散文残留、失败窗口或人工处理窗口。20 个普通词裁决全部进入负缓存，活动普通词锚点为 0。

法语和西班牙语本轮完成的是导入、检测、章节、残留检查和翻译协议的工程回归，不代表已经完成同等级的出版质量评测。

## 下载与升级

- 推荐下载 `FolioLoom-portable-win-x64.zip`，完整解压后运行根目录的 `FolioLoom.exe`。
- 同时提供单文件 `FolioLoom-portable-win-x64.exe`。
- 目录版中的 `resources`、`locales` 和 DLL 都是运行所需内容，请勿只移动根目录 EXE。
- 旧项目和 SQLite 状态库无需转换；若旧项目保存的是已停用 DeepSeek 模型，需要重新选择 V4 Flash 或 Pro 并测试连接。
