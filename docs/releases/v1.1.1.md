# FolioLoom v1.1.1

FolioLoom v1.1.1 是 v1.1 桌面版的小型修复更新。

## 本次修复

- 已保存的 API Key 现在会在输入框中以圆点占位显示，让用户能够确认密钥仍然存在。
- 占位圆点只表示“已安全保存”，页面仍然无法读取或恢复密钥明文。
- 用户开始输入新密钥时，占位会自动让位；清空输入框不会误删已保存的密钥。

## 下载方式

- **FolioLoom-portable-win-x64.zip（推荐）**：解压后运行 `FolioLoom.exe`。
- **FolioLoom-portable-win-x64.exe**：单文件便携版。
- **SHA256SUMS.txt**：用于校验下载文件。

两个程序包均仅支持 Windows x64。项目没有捆绑模型或 API Key，首次使用时需要接入自己的模型服务。由于当前程序尚未购买代码签名证书，Windows 可能显示 SmartScreen 提示。

建议先导入一小段自己有权处理的文本完成试译，再启动长篇任务。
