# FolioLoom v1.12.1

Direct translation now allows eight provider attempts per window by default,
up from four. Nested structural splits can use the additional attempts while
replaying successful saved fragments instead of translating them again.

- Explicit `--max-attempts` values range from 1 to 16. Existing requests still
  count toward the selected limit; restarting does not reset the allowance.
- Scoped transport releases still add 1–4 attempts at a time, with a lifetime
  ceiling of 16. They remain restricted to transport-only failures.
- Existing transport grants retain their recorded base limit when no override
  is supplied, in both execution and recovery status.
- Source, model, prompt and window identities are unchanged. Response evidence,
  usage records and completed translations remain intact. Existing token
  envelopes are not renewed by raising the attempt count.

## 中文

直译窗口的默认调用额度从 4 次提高到 8 次。多层结构拆分可使用新增额度，
已经成功的子片段会复用原响应，无需重新翻译。

- `--max-attempts` 支持 1–16；历史请求计入上限，重启不会重置次数。
- 纯传输失败仍须显式释放恢复额度，每次增加 1–4 次，累计最多 16 次。
- 未显式指定上限时，已有传输恢复记录沿用原基础额度。
- 原文、模型、提示词和窗口身份不变；保留响应证据、用量与已提交译文。
  提高调用次数不会重置已有 token 预算。
