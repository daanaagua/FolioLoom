# parallel_v4 第二版实施计划

1. 将SQLite schema升级为第二版，增加基线、段落映射、声明、核验票、注释和修复任务表。
2. 实现DOCX逐段导入器，严格验证来源版本、段落数量、文件哈希和文本块交集。
3. 扩展对照报告，使外部DOCX基线优先于不完整的 `serial_v3` 基线。
4. 实现高影响判定、两个独立核验调用和未决假说存储；只注入已验证且已到揭示位置的约束。
5. 实现绑定 `127.0.0.1` 的Web裁决服务，所有写请求校验随机令牌。
6. 实现局部块修复器，严格校验等长段落数组并版本化提交结果。
7. 实现注释的添加、审批、拒绝以及可选TXT/EPUB导出。
8. 增加第二版单元测试，并分别用《新日之书》和 `Incandescence` 执行非破坏性验收。
